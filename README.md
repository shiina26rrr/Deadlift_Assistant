# 硬拉辅助检测 v1.1.1

使用侧面摄像头或本地视频查看硬拉动作、记录完成次数，并在一组结束后获得反馈。适用于 Windows x64，当前为演示预览版。

## 下载哪个文件

- **直接使用**：下载 `deadlift-assistant-1.1.1-win-x64.zip`。
- **修改源码**：下载 `deadlift-assistant-1.1.1-source.zip`，按其中的开发文档安装依赖。

普通使用请选择 Windows 运行包。运行包无需安装 Node.js、Python，也无需配置 AI 接口。

## 启动

完整解压 Windows 运行包，进入 `win-unpacked`，双击 `DeadliftAssistant.exe`。请保留目录中的全部文件，不要单独移动 EXE 或在压缩包预览中启动。

## 开始训练

1. 摄像头放在身体侧面约 2–3 米、腰部高度，保证头部至脚踝完整入镜。
2. 打开摄像头，选择计划训练或自由训练，按提示站直并保持约 2–3 秒。
3. 校准完成后默认倒计时 6 秒开始，完成训练后点击“结束一组”。
4. 在“本组记录”查看次数、角度范围和建议，后续可从历史记录回看。

已有训练录像可通过“导入本地视频”分析。详细步骤、语音和在线反馈设置见[使用说明](QUICK_START.zh-CN.md)。

## 使用前请了解

仅支持单人侧面的传统杠铃硬拉。遮挡、出画、身体转向和光照不足会降低识别可靠性。本地动作模型是实验性参考，可能误判，也可能因数据不足不作判断；具体结果见[模型说明](MODEL_CARD.md)。

当前版本尚未完成摄像头兼容性和不同 Windows 显示缩放环境的全面验证。程序尚未签名；请从可信来源下载，必要时用 `SHA256SUMS.txt` 核对文件。

程序不测量腰椎曲率。未提示问题不代表动作标准或可以增加负重。

本工具仅作为初学者练习辅助参考，存在算法误差，不能够替代专业健身教练，请勿直接依据该软件判断大重量训练安全性。
