# 本地动作模型说明

本页面说明硬拉辅助检测 v1.1.1 中实验性动作模型的用途、数据来源和评估结果，帮助理解报告里的“本地动作模型参考”。它不代替训练者或教练的判断。

## 用途

模型在本机分析已提取的动作特征，给出数据集中的动作模式参考；数据不足、结果不稳定或把握不足时可以不作分类。角度读数、规则观察和模型参考是不同信息，不应把其中任何一项当作安全认证。

| 数据集类别 | 原始含义 | 解释边界 |
| --- | --- | --- |
| GB | 数据集标注的正确动作 | 预测为 GB 不表示动作完全标准或可以加重。 |
| PB | 数据集标注的圆背动作 | 预测为 PB 不是腰椎屈曲测量或诊断。 |
| LLK | 数据集标注的膝盖超过脚尖动作 | 预测为 LLK 不表示膝盖超过脚尖在所有情况下都是错误。 |

## 模型与数据

- 模型版本：`dl-action-v3`；特征版本：`feat-3`；状态：**实验性（EXPERIMENTAL）**。
- 本版使用 20 维角度、位移、时长和有效性统计特征，不包含身体比例。单目身体比例估计仅作为校准参考保留。
- 数据来源：[MyDeadlift Dataset，Version 1](https://data.mendeley.com/datasets/w5prmmxyt9/1)，作者 Ivan Conanta、Gloria Virginia，CC BY 4.0。
- 原数据为 7 名男性参与者的 191 段侧面单次动作视频。按本版协议处理后，181 段可分段、10 段无法完成分段。
- 训练与测试按参与者隔离；可分段样本中训练侧 122 段、测试侧 59 段。测试参与者为 2 人，不能据此代表所有体型、性别、机位和训练环境。

## 已有评估结果

以下为随该模型保存的评估记录，不是针对当前使用者的识别准确率。

| 指标 | 结果 |
| --- | --- |
| 测试准确率（accuracy） | 49.2% |
| 宏平均 F1（macro-F1） | 0.495 |
| 平衡准确率（balanced accuracy） | 49.0% |
| 多数类基线准确率 | 33.9% |
| 阈值筛选后接受的测试样本 | 37 / 59 |
| 接受样本的准确率 | 40.5% |

效果仍有限，不能将本版描述为可靠的专业纠错系统或准确率提升。模型概率也不等于动作正确率。

## 使用限制

单目关键点无法恢复被遮挡的身体部位，也不能从肩髋连线测量腰椎曲率。衣物、光照、旋转、摄像头角度和动作片段边界都会影响结果。身体比例不是精确体测；当前模型也没有按每位使用者重新训练。

出现模型无法判断或与其他观察不一致时，应结合原视频复核。未发现异常不代表动作标准，更不能用于判断大重量训练安全性。

开发者可在源码包的 `training/MODEL_CARD.md`、`training/README.md` 和 `dataset/metrics.json` 中查看完整训练协议、逐类指标与复现说明。
