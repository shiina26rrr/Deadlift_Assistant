# 使用说明

硬拉辅助检测适用于 Windows x64 电脑，通过侧面摄像头或本地训练视频显示动作骨架、关键角度和完成次数，并在一组结束后提供反馈。

## 下载与启动

在项目的 **Releases** 页面下载 `deadlift-assistant-1.1.1-win-x64.zip`，完整解压后进入 `win-unpacked`，双击 `DeadliftAssistant.exe`。

请保留解压目录中的全部文件，不要只复制 EXE，也不要在压缩包预览中直接启动。使用运行包无需安装 Node.js、Python 或额外下载模型。

`deadlift-assistant-1.1.1-source.zip` 是供开发者修改程序的源码包，不能解压后直接运行。

## 放置摄像头

将摄像头放在身体侧面约 **2–3 米**，镜头高度约在腰部，保持水平。画面至少应包含头部到脚踝，尽量让肩、肘、腕、髋、膝和踝清晰可见。

本程序仅支持单人、侧面拍摄的传统杠铃硬拉。身体转向镜头、杠铃遮挡、宽松衣物、逆光或出画都会影响结果。

## 使用摄像头

1. 选择摄像头，点击“打开摄像头”。
2. 选择训练模式：计划训练可设置组数和每组次数；自由训练不设目标次数。
3. 按引导框上方的提示调整位置，完整入镜后站直并保持约 2–3 秒，等待站立校准。
4. 校准完成后，默认倒计时 6 秒开始本组。可在“设置 → 高级参数”中将倒计时设为 5–7 秒。
5. 完成本组后，放稳杠铃，再点击“结束一组”，查看下方“本组记录”。

达到计划次数时会提示达标，由你决定何时结束本组。更换训练者或移动摄像头后，请重新校准。校准用于建立参考姿态，不代表程序已确认动作正确。

## 分析本地视频

点击“导入本地视频”，选择清晰的侧面训练录像。建议先使用 MP4 视频；若无法播放，请换用其他视频文件。

确认画面和参考姿态后，按界面提示点击“开始一组”。视频正常播放结束或手动点击“结束一组”后，可查看报告。画面缺少头部、脚踝或站立参考时，按提示调整素材；导入视频中的拍摄缺陷无法通过移动当前设备修复。

## 阅读训练报告

报告展示完成次数、时长、有效数据比例、各项角度范围和主要建议。历史记录可以在应用中回看，按日期了解组数、次数和训练时长。

| 内容 | 怎样理解 |
| --- | --- |
| 手臂与地面夹角 | 肩到手腕连线相对画面水平线的角度。 |
| 肘、膝关节内角 | 关节处的弯折情况，接近 180° 表示接近伸直。 |
| 躯干倾角 | 肩到髋连线相对竖直方向的倾斜程度，不是腰椎弯曲程度。 |
| 不可用 / 数据不足 | 相关关节点不可见或不够可信；不能将它理解为动作正常。 |
| 本地动作模型参考 | 实验性的动作模式提示，可能误判或无法判断。 |

建议结合整组报告回看训练，不必在动作过程中一直看屏幕。次数、时长增加只表示训练量变化，不直接代表动作质量提升。

## 离线、语音和在线反馈

姿态识别、角度计算、本地模型和内置文字反馈所需资源已随运行包提供。基础功能不需要配置 AI 接口。

如需组后播报，可在“设置”中开启“组后中文语音播报”。语音使用系统的本地中文语音；没有可用语音时仍可查看文字报告，也可手动停止或重播总结。

“在线润色”默认关闭。启用后需填写接口地址、模型名称和 API Key，只发送必要的匿名整组摘要来调整反馈措辞，不向该文字接口发送训练视频或图像。接口不可用时保留内置反馈，Key 仅在当前会话使用。

报告保存在本机，程序不自动保存训练录像。

## 常见问题

**摄像头打不开**：检查 Windows 是否允许桌面应用访问摄像头，并关闭可能占用摄像头的其他软件；也可以先使用本地视频。

**一直无法完成校准**：检查头部到脚踝是否完整入镜，保持侧面站直、光照清晰，并静止约 2–3 秒。调整位置后可点击“站立校准”重试。

**角度显示不可用或计次不准**：先检查遮挡和机位。程序需要识别起拉到站直的过程，视频一开始就在站立状态不会直接算一次；无法识别完整动作时可能漏计。

**没有中文语音**：检查设置中的语音开关和 Windows 本地中文语音。语音不可用不影响文字反馈。

**窗口有裁切或错位**：尝试调整窗口大小。如果仍有问题，请通过项目 Issues 提供应用版本、Windows 版本、分辨率、显示缩放比例和截图。

**Windows 提示发布者未知**：当前程序尚未签名。请核对下载来源；需要校验时，在 PowerShell 执行 `Get-FileHash -Algorithm SHA256 文件路径`，与同一版本的 `SHA256SUMS.txt` 对照。

## 使用限制

当前为演示预览版，摄像头兼容性和不同 Windows 显示缩放环境尚未完成全面验证。本地动作模型仍处于实验阶段，具体评估见项目的模型说明。

程序不测量腰椎曲率，也不根据某个膝角或躯干角给出统一的合格结论。没有提示问题，不代表动作标准或适合增加负重。

本工具仅作为初学者练习辅助参考，存在算法误差，不能够替代专业健身教练，请勿直接依据该软件判断大重量训练安全性。
